# finleo_demo Задания:
1. Чек-лист из 5–10 проверок, которые вы выполнили бы для тестирования этой функциональности https://gitlab.com/users/sign_up
2. SQL-запрос выводит:
имя пользователя;
количество его заказов.
из двух таблиц:
users: id, name
orders: id, user_id, price

3. Напишите функцию, которая принимает список чисел и возвращает новый список, содержащий только четные числа.
4. Баг-репорт для ситуации:
При регистрации нового пользователя:
пользователь заполнил все обязательные поля корректно;
нажал кнопку «Зарегистрироваться»;
появилось сообщение «Регистрация прошла успешно»;
однако пользователь не был создан в системе и не может войти в аккаунт.
